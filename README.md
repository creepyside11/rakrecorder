# RakRecorder Studio — экспериментальная разработка

Импорт PCAP, локальные сессии, ручные отметки и ZIP-экспорт. Также ведётся разработка встроенного локального VPN на zdtun; функциональность VPN не проверена на Android и может не работать. Для захвата нужно указать точное имя установленного приложения и разрешить VPN. Сырые файлы содержат чувствительные данные; экспорт включает их только с разрешения пользователя.

Добавлена экспериментальная панель поверх игры с ручными отметками; проверка на Android-устройстве ещё не проводилась. Не реализованы: подтверждённое декодирование игровых XYZ, автоматический маршрут, полноценная работа с мини-играми, запись экрана и другие функции полного ТЗ. PCAPNG не поддерживается. Некоторые виды и нестандартные сочетания IPv6-расширений могут остаться нераспознанными. Наличие порта само по себе не доказывает принадлежности к игре.

VPN-движок zdtun: https://github.com/emanuele-f/zdtun, commit 4a53fbbbfc16ed012af676a871dd989f3583a5e6, лицензия LGPL-3.0-or-later; копия лицензии находится в app/src/main/cpp/zdtun/COPYING.

GitHub Actions собирает debug APK и запускает unit-тесты. Стабильная подпись релизов не настроена.
