# RakRecorder Studio — ранняя альфа

Приложение хранит импортированные классические PCAP (RAW IP или Ethernet) и ручные отметки локально, показывает базовую статистику, экспортирует ZIP через системный выбор файла. Исходный PCAP в экспорт включается только по явному выбору пользователя и может содержать чувствительные данные. Ручные отметки привязываются к времени, введённому пользователем, координаты неизвестны.

**Не реализованы:** VPN и пересылка трафика, живой захват, автоматический маршрут/XYZ и игровые события, панель поверх игры, декодирование RakNet, мини-игры и запись экрана. Продукт ещё не соответствует полному ТЗ. PCAPNG не поддерживается. IPv6 с заголовками расширения учитывается как нераспознанный, порт не доказывает принадлежность к игре.

GitHub Actions собирает debug APK и запускает unit-тесты. Для локальной сборки необходимы JDK 17, Android SDK 35 и Gradle 8.10.2: `gradle testDebugUnitTest assembleDebug`.
