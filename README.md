# RakRecorder — ранний прототип

Пока реализован только локальный импорт классического PCAP (RAW IP или Ethernet) и подсчёт пакетов TCP, UDP и UDP-пакетов с портами 5125 и 5127. IPv6 с заголовками расширения учитывается как нераспознанный. Данные не загружаются в сеть. Приложение не определяет, является ли трафик игровым.

**Не реализованы:** VPN и пересылка трафика, захват пакетов, маршрут/XYZ, события, плавающая панель, расшифровка, экспорт ZIP, скриншоты. Это не готовый RakRecorder по ТЗ. PCAPNG не поддерживается. Сборка отладочная, не предназначена для публикации как готовый релиз.

GitHub Actions запускает unit-тесты и создаёт debug APK в артефактах workflow. Для локальной сборки необходимы JDK 17, Android SDK 35 и Gradle 8.10.2: `gradle testDebugUnitTest assembleDebug`.
